# Nama yang Tumbuh Bersama Waktu (Fazaa)

> *“Fazaa — Dari Sebuah Nama, Menjadi Sebuah Kisah”*  
> Sebuah novel digital sastra autobiografi karya Fazle & Azalia.

---

## 📖 Tentang Karya Ini
Website novel digital interaktif bergenre sastra naratif personal. Mengisahkan perjalanan rasa dari pertemuan pertama di bangku SDN Bendan Ngisor, jeda panjang bertahun-tahun, penciptaan nama motor **Fazaa** di kelas 9 sebagai penggabungan nama *Fazle* dan *Aza*, hingga babak pembuktian di konser Perunggu pada 2 Juli 2026.

### ✨ Fitur Unggulan
- **Pengalaman Membaca Sastra Editorial**: Tipografi kurasi (*Cormorant Garamond*, *Lora*, *Caveat*) dengan drop cap dan pilihan tema kertas (*Ivory*, *Paper*, *Sepia*, *Dark*).
- **Progressive Web App (PWA)**: Dapat dipasang langsung di layar utama smartphone (Android & iOS) layaknya aplikasi mandiri tanpa peramban.
- **Musik Latar Terintegrasi**: Lagu pengiring tunggal *Sampai Jadi Debu* oleh Banda Neira, tersinkronisasi mulus di seluruh bab hingga pemutar piringan hitam di bab khusus *Sneha dalam Mauna*.
- **Galeri & Arsip Kenangan**: Integrasi potret nyata beresolusi tinggi (kado 16 Maret, tiket konser Perunggu, potret kebersamaan 2 Juli 2026).
- **Peta Waktu (Timeline)**: Linimasa kronologis interaktif dari tahun 2017 hingga 2026.
- **Penanda Halaman (Bookmark) & Progres Membaca**: Tersimpan otomatis secara lokal di peramban pembaca.

---

## 🛠️ Teknologi yang Digunakan
- **Framework**: [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Bahasa**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animasi**: [Framer Motion](https://www.framer.com/motion/)
- **Ikonografi**: [Lucide React](https://lucide.dev/)
- **PWA**: Web App Manifest & Service Worker Cache Engine

## 🚀 Menjalankan Secara Lokal

```bash
# 1. Unduh repositori
git clone https://github.com/FazleDzakyA/namayangtumbuh.git
cd namayangtumbuh

# 2. Pasang dependensi
npm install

# 3. Jalankan server pengembang
npm run dev

# 4. Bangun untuk produksi
npm run build
npm start
```
